\begin{abstract}
    Le paquet \thisproj\,%
    \footnote{
        Le nom vient de \tdocquote{\tdocprewhy{t.ype} \tdocpre{n} (and) \tdocprewhy{s.ee} \tdocprewhy{func.tion} \tdocprewhy{tab.le}} qui se traduit en \tdocquote{taper et voir des tableaux de fonctions}.
    }
    fournit des moyens intuitifs et efficaces pour taper de petits tableaux de données, ainsi que des tableaux de signes et de variations de fonctions mathématiques% remplies éventuellement via des \tdocquote{fonctions informatiques}
    %\footnote{
    %	La référence à \tdocquote{fonction} est donc polysémique.
    %}
    , ceci se faisant efficacement via un langage de saisie intuitif.%
    \footnote{
        Le terme technique est \dsl\ soit \tdocquote{Domain Specific Language} qui signifie \tdocinEN{Langue spécifique à un domaine}\,.
    }
    Voici les types de tableaux disponibles.
    \begin{enumerate}
    	\item Tableaux de données remplis à la main.% ou via une macro.
    
    %	\item Tableaux de données pour des suites récursives remplis à la main et/ou via une macro.
    %
    %	\item Tableaux de signes et/ou de variations de fonctions réelles.
    %
    %	\item Tableaux de signes et/ou de variations associées à des courbes planes paramétrées réelles.
    \end{enumerate}
    
    \medskip
    
    \noindent
    Deux points importants à noter.
    \begin{itemize}
        \item Sans le paquet \tdocpack{nicematrix} qui fait tout le travail ingrat, le paquet \thisproj\ n'aurait certainement pas vu le jour.

        \item Cette documentation est aussi disponible en <<DOC-LANGS>>.
    \end{itemize}
\end{abstract}
