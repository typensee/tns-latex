Le paquet \thispack\ fournit des moyens intuitifs et efficaces pour taper de petits tableaux de données, ainsi que des tableaux de signes et de variations de fonctions mathématiques% remplies éventuellement via des \tdocquote{fonctions informatiques}
%\footnote{
%	La référence à \tdocquote{fonction} est donc polysémique.
%}
, ceci se faisant via un langage de saisie intuitif.
\footnote{
    En informatique, on parle de \texttt{DSL} soit \tdocquote{Domain Specific Language}\,, c'est-à-dire \tdocinEN{Langue spécifique à un domaine}\,.
}
Voici ce qui est proposé pour cette toute première version.
\begin{enumerate}
	\item Tableaux de données remplis à la main.% ou via une macro.

%
%	\item Tableaux de signes et/ou de variations de fonctions réelles.
%
%	\item Tableaux de signes et/ou de variations associées à des courbes planes paramétrées réelles.
\end{enumerate}

\textbf{Abstract.}
The \thispack\ package provides intuitive and efficient means of typing small data tables, as well as tables of signs and variations of mathematical functions% possibly filled in via \tdocquote{computer functions}
%\footnote{
%	The reference to \tdocquote{function} is therefore polysemous.
%}
, this is done via an intuitive input language.
\footnote{
    In computing, we speak of \texttt{DSL} or \tdocquote{Domain Specific Language}\,.
}
Here is what is proposed for this very first version.
%Here is what is currently proposed.
\begin{enumerate}
	\item Data tables filled in by hand.% or via a macro.

%	\item Tables of data for recursive sequences filled in by hand and/or via a macro.
%
%	\item Tables of signs and/or variations of real functions.
%
%	\item Tables of signs and/or variations associated with real parametric plane curves.
\end{enumerate}

    \item This documentation is also available in French.
\end{itemize}
