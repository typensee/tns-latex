\subsubsection{Le contexte \tdoclatexin{mat} pour les images}

Le contexte \tdoclatexin{mat} s'utilise comme le contexte \tdoclatexin{imgs}
\footnote{
    Se reporter à la section \ref{tns-math-functab-dsl-l3-ctxt-imgs} si besoin.
}
aux différences près suivantes.
%
\begin{enumerate}
    \item L'emploi de \tdoclatexin{mat} se fait une fois par ligne de la matrice des données.
    Sémantiquement, on indique \tdoclatexin{e_i1 , e_i2 , ... , e_in} où chaque \tdoclatexin{e_ik} sert à donner la valeur, éventuellement vide, de l'entrée dans la ligne \tdoclatexin{i} et la colonne \tdoclatexin{k}\,.

    \item Seul le 1\ier\ emploi de \tdoclatexin{mat} permet de changer le nom de l'expression, $f$ étant celle utilisée par défaut.
\end{enumerate}


Voici un code fictif illustrant la logique de saisie.

\tdoclatexinput<\tdoctcb{code}>{examples/dsl-l3/imgs-2D.tex}
