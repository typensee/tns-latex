\section{Présentation rapide}

La rédaction du contenu des tableaux se fait via \tdocenv{functab} qui attend comme contenu des directives basées sur un langage spécifique simplifiant la saisie des informations.
Cet environnement est assez \tdocquote{malin} pour deviner le type de tableau souhaité en fonction des instructions fournies, comme nous le constaterons dans cette documentation.
