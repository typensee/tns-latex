\section{Présentation rapide}

La rédaction du contenu des tableaux se fait via \tdocenv{functab} qui attend comme contenu des directives basées sur un langage spécifique simplifiant la saisie des informations.
Cet environnement est assez \tdocquote{malin} pour deviner le type de tableau souhaité en fonction des instructions fournies, comme nous le constaterons dans cette documentation.


\begin{tdocimp}
	Dans la suite, nous emploierons le terme \tdocquote{contexte} pour indiquer un contexte d'utilisation, ou bien le nom de la variable indiquant ce contexte. Par exemple, dans le code suivant sont indiqués les contextes
	\tdoclatexin{xvals},
	\tdoclatexin{signs}
	et
	\tdoclatexin{vars}.%
	\footnote{
		Le code devrait être facile à décrypter grâce à la mise en forme du code qui contient des espaces ignorés lors de l'analyse faite par \thisproj. 
	}
	
	\tdoclatexinput<\tdoctcb{code}>{examples/main/tab-signs-vars.tex}
\end{tdocimp}


\begin{tdoccaut}
	\thisproj\ a été conçu dans un objectif précis : faciliter la saisie courante de petits tableaux dans l'enseignement pré-universitaire en mathématiques. Il ne faut pas lui prêter des intentions qu'il n'a pas. 
\end{tdoccaut}
