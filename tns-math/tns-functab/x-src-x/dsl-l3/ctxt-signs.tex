\subsubsection{Le contexte \tdoclatexin{signs} pour les signes}

Voici tous les éléments de syntaxe propres au contexte \tdoclatexin{signs}\,.
%
\begin{enumerate}
    \item Le contexte \tdoclatexin{signs} est employable autant de fois que nécessaire.


    \item Un seul contexte \tdoclatexin{signs} peut ne pas nommer l'expression pour utiliser $f$ le nom par défaut, les autres devront le faire via \tdoclatexin{monexpr : ...} où les points de suspension spécifient les informations liées au comportement de l'expression (voir l'item suivant à ce sujet).


    \item Dans cet item, pour expliquer ce qui est attendu comme informations relatives au comportement d'une expression $f$\,, qui est le nom par défaut, nous allons supposer que $n$ valeurs pivots \tdoclatexin{x1}\,, \tdoclatexin{x2}\,, \dots\ , \tdoclatexin{xn} ont été données via \tdoclatexin{xvals = x1 , x2 , ... , xn}\,. Nous posons aussi $p = n - 1$ avec \tdocpre{p} pour \tdocquote{\tdocprewhy{p.récédent} le naturel $n$}\,.
    %
    \begin{itemize}
        \item On peut indiquer
        \tdoclatexin{s1 s2 ... sp}
        où
        \tdoclatexin{s1} , \tdoclatexin{s2} , \dots\ , \tdoclatexin{sp}
        donnent des informations sur les $p$ intervalles
        \tdoclatexin{]x1 ; x2[} , \tdoclatexin{]x2 ; x3[} , \dots\ , \tdoclatexin{]xp ; xn[} respectivement.
        Les valeurs possibles pour les \tdoclatexin{sk} sont les suivantes.
        %
        \begin{enumerate}
            \item \tdoclatexin{+} indique une expression positive stricte sur l'intervalle concerné.

            \item \tdoclatexin{-} indique une expression négative stricte sur l'intervalle concerné.

            \item \tdoclatexin{z} indique une expression nulle sur l'intervalle concerné avec \tdocpre{z} pour \tdocprewhy{z.éro}.

            \item \tdoclatexin{u} indique une expression non définie sur l'intervalle concerné
            \footnote{
                Penser par exemple à l'expression $x \, \sqrt{x^2 - 1}$ .
            }
            avec \tdocpre{u} pour \tdocprewhy{u.ndefined} soit \tdocinEN{non défini}.
        \end{enumerate}


        \item On peut aussi indiquer le comportement en certaines valeurs pivots. Ceci se fait à côté d'une information de type signe : par exemple, en gardant les notations de l'item précédent, nous avons les possibilités suivantes.
        %
        \begin{itemize}[label={\scriptsize o}]
            \item Si $n > 3$ alors $f(x_3) = 0$ s'indique via \tdoclatexin{... s2 0 s3 ...} au milieu du code.

            \item Si $n = 3$ alors $f(x_3) = 0$ s'indique via \tdoclatexin{... s2 0} en fin de code.

            \item $f(x_1) = 0$ s'indique via \tdoclatexin{0 s1 ...}    au début du code.
        \end{itemize}
        %
        Les valeurs possibles pour le comportement éventuel en un pivot sont les suivantes.
        %
        \begin{enumerate}
            \item \tdoclatexin{0} indique que
l'expression s'annule au pivot concerné.

            \item \tdoclatexin{!} indique que
l'expression n'est pas définie au pivot concerné.
            \footnote{
                En France, le panneau de signalisation indiquant un danger est un triangle blanc aux bords rouges, et contenant un point d'exclamation.
            }

            \item L'absence de valeur indique que l'expression admet une valeur non nulle au pivot concerné.
        \end{enumerate}


    	\item \textbf{Il est possible de renseigner une ligne partiellement.}
    \end{itemize}
\end{enumerate}
