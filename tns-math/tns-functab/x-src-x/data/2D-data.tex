\subsection{Tableaux d'images d'une seule fonction à deux variables}

Voyons comment taper un tableau d'images d'une seule fonction à deux variables, ou de façon équivalente d'un tableau à double-entrée.
\footnote{
	Bien entendu, on perd ici la possibilité de travailler avec plusieurs fonctions au sein du même tableau.
}


% --------------- %


\begin{tdocexa}[Avec des étiquettes de partout]
    En plus de \tdoclatexin{xvals} pour les colonnes, il faut utiliser \tdoclatexin{yvals} pour renseigner les valeurs des lignes.
    Quant aux valeurs des cellules, elles se donnent comme suit.
    %
    \begin{itemize}
    	\item Le contexte \tdoclatexin{mat} permet d'employer une écriture matricielle.

    	\item Pour une ligne, les valeurs sont séparées par des virgules.

    	\item Les points-virgules permettent de passer à la ligne suivante.
    \end{itemize}

    \tdoclatexinput{examples/2D-data/label.tex}
\end{tdocexa}
